# Memory Discipline

Before substantial work:

1. Recall relevant memory.
2. Check project scope.
3. Check recent lessons.
4. Check previous decisions.

When a decision becomes stable:

1. Save the decision.
2. Save the reason.
3. Associate it with the project.

When the user corrects the agent:

1. Do not merely save the conversation.
2. Convert the correction into a lesson.
3. Assign confidence.
4. Reuse the lesson later.
