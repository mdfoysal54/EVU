# Memory Lesson

When the user corrects a recurring behavior:

1. Identify the mistake.
2. Identify the correct behavior.
3. Write a concise reusable rule.
4. Store the rule as a lesson.
5. Attach project scope when applicable.
6. Assign initial confidence.
7. Increase confidence when reinforced.
8. Supersede the lesson if later evidence contradicts it.
