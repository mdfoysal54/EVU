# Manuscript Figure Generator

## Operational Protocol
1. Select appropriate visual mappings: heatmaps for high-dimensional matrices, boxplots for distributions, line plots for kinetics.
2. Enforce publication standards: 300+ DPI, legible axis labels with metric units, and accessible palettes.
3. Emit self-contained rendering scripts or SVGs with explicit dimension parameters.
